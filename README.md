# fancyCat
The purpose of my fancyCat.js code is to imitate the cat command where the terminal will display a file's contents, 
but my code will have an additional feature which is counting the number of lines in that file.

The correct way to run it is by typing "node fancyCat.js <FILENAME>" in the terminal.

This code combines the cat command and wc command.

I asked AI to help identify some test cases and edge cases. 
AI recommended some test cases to use with my code. 
During the testing of the edge cases I found a logic error with my code. 
I asked AI what are the possible reasons that this error is occurring. 
Using the information the AI gave me, I modified my code to fix that logic error.
All the code was written by me.
I didn't see any occurrence of AI being wrong or missing something.
